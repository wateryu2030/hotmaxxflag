## 一、数据基础说明

### 1.1 数据来源与口径

**薪资数据**：来自 `~/Downloads/` 目录下 5 份 Excel：
- 2025-11：`to斗米：202511人力外包服务费明细12.12-沈阳(1).xlsx`（仅斗米1人）
- 2025-12：`12月薪资表-沈阳金融中心 - 更新.xlsx`
- 2026-01：`1月薪资表-沈阳金融中心 -剔除店长更新版.xlsx`
- 2026-02：`沈阳金融中心26年2月薪资表-V3-沈阳-最终版.xlsx`
- 2026-03：`202603-沈阳-薪资最终版.xlsx`

**成本口径**：按 Excel 合计表「开票金额/总成本」列，即
= 薪资成本 + 税费服务费 + 社保公积金成本（管理岗）

**销售数据**：来自 `t_htma_sale` 表，为实际 POS 出库数据

### 1.2 当前数据库的限制

当前 `t_htma_labor_cost` 表存的是**合计表汇总行**（如"斗米全职53人合计"），而非到人明细。原因是明细级导入时，每个 sheet 底部的合计行会被误当作人员行，导致数据翻倍（如3月从48人翻到75人、成本从23.7万翻到40.9万）。

要支持后续扩展到「按人员逐月跟踪」的分析，需要：
- 方案 A：将 Excel 的到人明细正确解析后重新入库（需要修正导入脚本的合计行过滤逻辑）
- 方案 B：在当前合计表口径基础上，将分析维度限制在岗位类别级别（全职/管理组/兼职/小时工/保洁）

## 五、管理效能综合评价

### 5.1 人力成本效率曲线

**人力成本占毛利比趋势：55% → 29% → 24% → 32%**

12月是典型的"粗放用工"阶段——大量兼职/小时工支撑春节前高峰，但效率低。
1-2月大幅优化后，3月略有回升。

**人效-成本比：**
- 每投入1元人力成本，产出：
  - 12月：5.6元销售额 / 1.8元毛利
  - 1月：11.0元销售额 / 3.5元毛利
  - 2月：13.0元销售额 / 4.2元毛利
  - 3月：9.1元销售额 / 3.1元毛利

2月是最优效率月。

### 5.2 结构健康度

**管理组占比（人数/成本）：**
- 12月：管理组16人/380总人 = 4.2%；成本占19.7%
- 1月：管理组15人/90总人 = 16.7%；成本占30.9%
- 2月：管理组12人/42总人 = 28.6%；成本占37.4%
- 3月：管理组11人/45总人 = 24.4%；成本占39.2%

管理组成本占比从20%上升到39%，管理幅度（每人管理组管多少人）从1:23降至1:3。
**这是一个值得关注的信号**：在团队精简过程中，管理层浓缩速度低于一线，管理效率在下降。
